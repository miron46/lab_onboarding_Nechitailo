# Деобфускация

## Расшифрованная строка
import os; os.system('rm -rf /')

## Анализ угрозы
Выполняется системная команда rm -rf / — рекурсивное удаление всех
файлов корневой файловой системы без подтверждения. Последствия:
полная потеря данных, неработоспособность ОС. При запуске от root —
необратимо.

## Методы защиты
1. Запрет exec/eval на уровне политики (bandit, ruff S102).
2. Статический анализ (Semgrep, flake8-bandit).
3. Sandbox/контейнер без root, read-only ФС.
4. Валидация входных данных, code review.
5. Запрет base64-строк в коде — детект паттернов.
