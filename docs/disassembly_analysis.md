# Анализ ассемблерного кода (x86-64, AT&T)

## Восстановленный код на Python

s = 0
i = 1
while i <= 10:
    s = s + i
    i = i + 1
return s

## Пояснение логики

Фрагмент реализует цикл, который считает сумму чисел от 1 до 10.

- Ячейка -4(%rbp) — аккумулятор (сумма), изначально 0.
- Ячейка -8(%rbp) — счётчик, изначально 1.
- jmp .L2 — переход к проверке условия.
- .L3 — тело цикла: счётчик прибавляется к аккумулятору, затем счётчик +1.
- .L2 — проверка: cmpl $10, -8(%rbp) сравнивает счётчик с 10,
  jle .L3 возвращает в тело цикла, пока счётчик <= 10.
- movl -4(%rbp), %eax — итоговая сумма кладётся в eax (возврат).

Итог: сумма чисел от 1 до 10 равна 55.
